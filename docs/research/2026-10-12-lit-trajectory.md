# Lit scan 2 — predicting agent-trajectory outcomes from action traces (2026-10-12)
Model-produced scan (Opus 5.5 subagent; arXiv abstract/HTML pages; "[snippet]" = search summary only). Spot-check before quoting.

1. Automata from Agent Traces (Cho et al., arXiv 2608.23670, 2026-08-24): next-step CE (bits, 5 datasets): n-gram LR 0.748, ESN 0.735, FSM+LR 0.729 (best); SWE-agent LR 0.687 vs ESN 0.691. Failure AUROC 0.799 (structure 0.790 vs length-only 0.659); 50% prefix = 92% of full AUROC. → reproduces our result: LR on n-grams ≈ learned sequence models; surprise features (trace CE, max surprise, min transition p) as FEATURES for failure prediction.
2. Fail-Fast, Restart-Smart (Wang et al., arXiv 2608.03222): early-stop + restart lifts Qwen3.6-27B SWE-bench Verified 66.6→71.8% at 25% FPR; saves 14.6–20.4% tokens at 5% FPR; 0.6B monitor trained on outcomes + dense fail-to-pass test signals.
3. EarlyEval (Shi et al., arXiv 2609.02783): two LightGBM heads (success/failure) on prefix features (volume/pacing, step composition, milestones, error/test signals, text); 89–97% accuracy, 13–26% steps eliminated. → our feature family; GBM on hand features is the SOTA here.
4. Last Step Matters (Li et al., EMNLP 2026, arXiv 2608.29685): verbal confidence at completion AUROC 0.85, but ≤0.60 at 50% progress (path switching). → report AUROC per prefix fraction.
5. Accurate Failure Prediction ≠ Effective Prevention (Vasudev et al., arXiv 2602.03338): critic with AUROC 0.94 caused −26 pp success when used to intervene; +2.8 pp only on high-failure ALFWorld; 50-task pilot to forecast harm.
6. Failure as a Process (Zhao et al., arXiv 2607.09510): 1,794 Terminal-Bench trajectories annotated; decisive error by step 7 (median), first observable signal step 16; successful runs respond to error signals 92% vs 37%; fabricated success in 26% of failed runs; κ 0.78–0.94.
7. Behavioral Drivers (Mehtiyev & Assunção, arXiv 2604.02547): length sign flips under task control (failed +14–112% longer across tasks; within task resolved runs longer 44.0 vs 39.6); step of first edit ρ +0.68, early patch share ρ −0.78, validation share ρ +0.50; 13-symbol action+response alphabet.
8. SWE-PRM (Gandhi et al., IBM, arXiv 2509.02360): taxonomy-guided inference-time PRM feedback +10.6 pp (40.0→50.6) at ~$0.2/task; prompted frontier LLM + taxonomy, not a trained PRM.
9. SWE-Critix (Hu & Chong, arXiv 2610.13356, 2026-10-09): trajectory-success accuracy 57→66 (SFT)→78 (RL) on ~43k held-out; needs 10k–258k trajectories; base LLM judge negative recall ≈ 0 (pass bias).
10. Agent Psychometrics (Ge et al., arXiv 2604.00594): task-level AUROC baseline 0.718, embedding 0.824, LLM-judge features 0.841, oracle IRT 0.945. → task difficulty prior before any step runs.
11. Calibration: Cao (arXiv 2609.25647) leave-one-agent-out transfer gaps 0.018/0.039 but agent-specific miscalibration up to 0.14; HTC (arXiv 2601.15778) argues end-to-end encoders need large data, process-level hand features calibrate better.
12. Judge reliability: AgentJudgeBench (2608.26623) [snippet] judges agree 79.1% (κ 0.419); iOSWorld (2606.09764) [snippet] judge vs human 89% (κ 0.77); Kim (2605.16354) doubly-robust judge+human design.
Lower weight: Agentic-JEPA (Zenodo 20237490) 100% ID / 0% OOD; TraceProbe (2607.06184); SWE-Shepherd (2604.10493); AgentLens (2605.12925) "lucky pass".

Synthesis: no 2025–26 paper shows learned latents beating hand/n-gram features at our scale; learned trace readers that win use 10k–250k labelled trajectories → our ~7% JEPA deficit is the expected result (data-bound, inference). What works with hundreds of labels: GBM/logistic on structure features + first-edit step, early patch share, error-response within k steps, mid-run test outcomes, surprise features from a next-action model. Caveats: length confounded with difficulty; prefix AUROC degrades; prediction ≠ safe intervention; AUROC SE ≈0.03 at ~110/110.
Experiments: (a) learning curve + linear probe on [hand ⊕ frozen JEPA latent]; (b) outcome predictor on 220 gold, nested CV, class-weighted GBM/logistic + surprise features, difficulty baseline, AUROC at 25/50/100% prefix; (c) judge label expansion via doubly-robust estimator + 50-task intervention pilot before any auto-abandon.
