## 3. Baseline pick: OpenAI Codex CLI

Codex uses plain words with one ` · ` separator, and every value has a unit and a word (`Context 61% used`, `5h 82% left`). It splits ambient facts (status line) from threshold warnings that name a command (`Run /status`) at 50/75/90/95 %. Its 90 % prompt only offers a model switch and the user decides, which matches the datapce advise-only rule.

Borrow from others: Claude Code color thresholds (70/90) and `COLUMNS`; Gemini "hide quota under 80 %" and narrow-width short labels; Aider "Use /x to …" verb hints.

## 4. Proposed bands (scorer rules checked locally: facts present, action regex correct, 0 OPAQUE hits)

Format: `apex LEVEL · [cause: action ·] figures`. Separator ` · `. No `●▲↑`. When an action applies, it comes right after LEVEL, so truncation drops figures, not the hint. Color only the LEVEL word and the cause cell.

No hint changes the model. "pause new subagents" and "slow down" are advice; the user acts.

## 5. Pane changes (`paneSections`)

1. Add a first section **Now** with one summary row, the band text plus the hint, e.g. `RED: 5h limit 95% used. Pause new subagents. Resets 14:20.`
2. New order: Now · Limits and budget (was Signals) · Subagents (was Dispatches) · Local models 24h (was Lanes 24h) · Track record (was Evidence) · About this session (was Profile).
3. Plain row words. Replace `▲ sonnet: …` with `advice: sonnet (…)`. Replace `tok(all) μ 12k` with `avg 12k tokens`. Replace `dur μ` with `avg time`. Replace ` n 25 ` with `25 runs`. Replace `breakers: codegen open` with `codegen paused after failures`. Replace `heavy spawns ≤ x/min (advisory)` with `suggest at most x large agents per min`. Replace `P(any slow)` with `chance one agent is slow`. Replace `settling` with `level drops after N calm checks`. Replace `burn 5m/60m` with `spend rate last 5 min / hour`. Replace `injection: arm` with `context added: N bytes`.
4. Row width 72 or less. Split a dispatch row into two lines: line 1 `description · task → model · outcome time`; line 2 (indented) `advice / tokens`. Truncate the description to 28 cols.
5. Show 10 dispatch rows, not 20. Put `/apex json` at the bottom for full data.
6. Keep the `NO_LABEL` note, but shorten: `ok% = finished and available, not answer quality`.

## 6. Top 5 rules (ranked)

1. Hint after level: when an action applies, write `cause: verb …` right after LEVEL, using a real command (`/compact`, `/apex`) where one exists (Codex, Aider).
2. Every number has a unit word: `5h 95% used`, `context 88%`, `$9.10/$10`, `3 agents`. No bare glyphs (Codex, Gemini).
3. Fit 72 cols with a fixed drop order; never truncate the hint (Gemini short labels, Claude Code `COLUMNS`).
4. Show a figure only when it matters: hide `5h` under a threshold, hide agent counts at 0 (Gemini quota < 80 %, ccstatusline hide-when-empty).
5. Color only the level and the cause cell, using the 70/90 thresholds. Text stays correct with no color (Claude Code docs).
